[ARQUITECTURA] Historia de Usuario 8 (Refinada): Gamificación Sensorial y Medidor Térmico Agnóstico (UI-UX)Estatus: Refinado / Listo para ImplementaciónMódulo: Interfaz de Usuario (Client Components / Tailwind CSS)1. Descripción GeneralComo turista interactuando con el conserje de BarcelonaXplorer,Quiero visualizar de forma sutil y orgánica cómo mis respuestas nutren la capacidad del sistema para forjar mi ruta,Para sentir el impulso psicológico de completar los datos sin percibir la fricción de un formulario rígido, sabiendo de un vistazo cuándo el orquestador ya tiene lo mínimo para operar.2. Justificación Arquitectónica (Zeigarnik, Fricción Cero y OCP)El diseño se fundamenta en el Efecto Zeigarnik (la urgencia por cerrar bucles incompletos) y el Gradiente de Meta. Sin embargo, para respetar el Principio de Abierto/Cerrado (OCP) y el dogma de Fricción Cero, el componente visual de React (Client Component) debe ser absolutamente agnóstico.
El medidor térmico no sabe qué es el "tiempo" o el "grupo". No contiene lógica de negocio ni umbrales estáticos (ej. 60%). Se limita a leer el objeto rules de la matriz activa y a reaccionar matemáticamente a la fórmula de pesos asimilados frente al survival_threshold, transmutando sus clases de Tailwind CSS en tiempo real.   3. Coreografía Visual (Estilado Atómico Táctico)El componente asume un diseño reactivo basado en tres estados termodinámicos universales, evaluados sobre el anillo perimetral del avatar del LLM ligero o el borde del input:Fase Inerte (suma_pesos < rules.survival_threshold):El medidor y el botón operan en tonos pasivos (ej. border-zinc-800, text-zinc-600).   La interfaz comunica latencia y el botón de acción principal ("Forjar Ruta") permanece en estado disabled.Desbloqueo de Supervivencia (suma_pesos >= rules.survival_threshold):En el milisegundo en que el usuario cruza el umbral exigido por la matriz, el componente rompe la latencia.El anillo muta a un acento funcional vibrante (ej. emerald-400) y emite un pulso sutil (animate-pulse).   El botón de acción se habilita. El usuario percibe instintivamente que el sistema ya es operativo.Saturación Táctica (suma_pesos == 100%):Al completar todos los vectores de enriquecimiento, el medidor térmico se cierra por completo.Se inyecta un feedback visual (micro-animación) y el agente ligero anuncia el desbloqueo del "Modo Explorador S+ Grade".4. Criterios de Aceptación (Verificación Empírica)Escenario 1: Componente Agnóstico en Fase InerteDado el medidor térmico renderizado en un cliente interactuando bajo la matriz "gastronomy" (Umbral 70%).Cuando el usuario acumula un 50% de densidad en el payload.Entonces el componente evalúa 50 < 70 y mantiene las clases de Tailwind en estado base inerte (zinc-800).   Y el botón de ejecución permanece bloqueado para forzar la clarificación asimétrica.Escenario 2: Activación Sensorial DinámicaDado el mismo usuario que proporciona el dato faltante y el payload alcanza el 80% (superando el umbral de 70%).Cuando el estado reactivo de React (useState / useMemo) recalcula la métrica.   Entonces la UI transiciona de forma fluida, iluminando el borde en emerald-400 y liberando el botón de acción principal sin requerir la completitud absoluta.   Escenario 3: Gamificación y Micro-Recompensa (Densidad Absoluta)Dado un usuario que completa todos los parámetros opcionales alcanzando el 100% de los weights de la matriz.Cuando el componente detecta la saturación termodinámica total.Entonces la recolección de datos se detiene visualmente.Y la interfaz inyecta un mensaje gamificado confirmando el desbloqueo de la hiper-personalización táctica.
