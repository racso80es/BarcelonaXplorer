Historia de Usuario 4: Sensor Termodinámico Vectorial (Telemetría LanceDB en - Admin - System)Estatus: Refinado / Listo para ImplementaciónMódulo: Administración, Telemetría y Órganos Sensoriales (/Admin/System)1. Descripción GeneralComo Operador Técnico y centinela del Nodo 11,Quiero ampliar la topología del panel de control /Admin/System incorporando un "Sensor C" dedicado exclusivamente a auditar la salud del motor vectorial embebido (LanceDB) y su volumen de persistencia,Para anticipar fallos de permisos en el sistema de archivos (Bind Mount), detectar corrupción en los índices vectoriales y garantizar que el cerebro cognitivo de la IA orquestadora esté operando en estado S+ Grade antes de inyectar tráfico real.2. Justificación Arquitectónica (Vía del Yunque)El módulo /Admin/System ya opera como la sala de máquinas del monolito, evaluando la persistencia híbrida (MySQL - Sensor A) y la aduana de red externa (DNS - Sensor B). Sin embargo, al ser LanceDB una base de datos embebida que carece de puertos de red externos, no puede monitorizarse mediante un simple ping o SELECT 1. Su punto de fallo crítico no es la red, sino la latencia de disco y los permisos del sistema de archivos anfitrión del Nodo 11.
Por tanto, la telemetría debe inyectar una sonda lógica de I/O (Lectura/Escritura) que evalúe la integridad física del volumen /app/vector_storage montado por Docker.   3. Coreografía de Telemetría (El Sensor C)Inmutabilidad Temporal Absoluta: La evaluación se ejecuta bajo la directiva estricta export const dynamic = 'force-dynamic'; de la ruta /Admin/System. Esto garantiza que Next.js no devuelva un estado cacheado del motor vectorial; la sonda se dispara en tiempo real con cada recarga del navegador.   Prueba de Conocimiento Vectorial (Healthcheck Interno): El Sensor C no se limita a verificar si el directorio existe. Ejecuta una operación atómica: conecta con la tabla de vectores, realiza un fetch de límite 1 (limit(1)) y evalúa el tiempo de respuesta (latencia).Auditoría de Permisos (Bind Mount Fallback): Evalúa proactivamente los derechos de escritura del usuario node (o el usuario de ejecución del contenedor Alpine) sobre el directorio externo mapeado para prevenir colapsos silenciosos al intentar guardar un nuevo vector.Volcado de Fricción en DataTable: Si el Sensor C detecta una anomalía (ej. base de datos bloqueada o permisos denegados), el error no solo cambia el semáforo visual del panel, sino que emite un log de nivel ERROR con el contexto LLM_ENGINE o SYSTEM, el cual será inmediatamente rastreable en la bitácora interactiva mediante el componente genérico DataTable<TelemetryEntry>.   4. Criterios de Aceptación (Verificación Empírica)Escenario 1: Resonancia Vectorial S+ Grade (Estado Óptimo)Dado el panel /Admin/System cargado por el operador.Cuando el Sensor C ejecuta la sonda hacia el directorio local de LanceDB.Entonces el sistema valida permisos de lectura/escritura y recupera un vector de prueba.Y la interfaz visualiza el "Sensor C (Motor Vectorial)" en estado Verde / OK mostrando la latencia de respuesta en milisegundos (ej. 3ms).Escenario 2: Asfixia por Permisos (Error de Bind Mount)Dado un despliegue donde el directorio físico en el Nodo 11 /home/racso/.../vector_data pertenece a root en lugar del usuario de Docker.Cuando el Sensor C intenta inicializar la conexión en /Admin/System.Entonces la sonda falla por EACCES (Permission denied).Y el semáforo cambia a Rojo / CRÍTICO, emitiendo una alerta visual explícita para que el operador ajuste el chown en el sistema anfitrión.Y el registro del fallo se inyecta en la tabla reactiva DataTable bajo el nivel ERROR.   Escenario 3: Corrupción o Tabla Inexistente (Inicialización de Emergencia)Dado un entorno virgen donde el volumen de LanceDB está vacío (primera instanciación).Cuando el Sensor C detecta que la tabla de vectores (ej. bx_conversations) no existe.Entonces el sensor arroja un estado Ámbar / ADVERTENCIA (Tabla no encontrada).Y ejecuta automáticamente (o habilita un botón táctico para que el operador ejecute) el script de migración que forja el esquema inicial vacío de la tabla en Apache Arrow, restableciendo el estado a verde.
